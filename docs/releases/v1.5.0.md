## Terraria AutoFish 1.5.0

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught, waits out Blood Moons and invasions and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables).

### Download
- **TerrariaAutoFish-1.5.0-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.5.0-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### New in 1.5.0
**Events and death**
- **Events in chat are waited out.** The game writes events in chat in green or purple; the program reads such a line and compares it with the game's texts: Blood, Pumpkin and Frost Moon and boss warnings — it reels in and waits one night (~9 min), solar eclipse — a day (~15 min), goblins, pirates, Frost Legion, martians, celestial invasion and a boss awakening — 10 min. Then fishing continues by itself (or press HOME). When an invasion is defeated ("A goblin army has been defeated!"), fishing continues at once.
- **The character died — fishing stops completely.** No red left in the health hearts (while the hotbar is visible, so the fullscreen map isn't taken for death): no automatic resume, also while an event is being waited out.

**The small window over the game shows the mode**: what is caught (everything or only checked with the Sonar Potion) and in which biome, the Angler quest, potions (and which aren't in the hotbar), what is watched, when to stop, how much bait is left and the last catch.

**Fishing**
- **A moved picture is followed.** If the character is pushed (an enemy, a fall), the whole picture moves and the old cast point may be over land. The program compares the place with its picture from the last successful cast and moves the cast point and the mark by the same amount instead of failing.
- **Sonar text over lava.** Lava and waves change all the time, and before the text seemed to be always there — its appearance was missed, and later several texts overlapped. Now colors already present nearby in the background are not taken for letters: on real lava screenshots the text is found and read ("Обсидирыба").
- **Zoom is recognized by itself** by the bobber's size on the first automatic search (100–200%) and saved in the settings.
- **Exact bait count and how long it lasts.** The number on the fishing rod is read by samples of the game's digits; only a confident read is used (otherwise the number of digits, as before).
- **Taking the rod:** a lost key press is repeated; keys are never pressed while the game window isn't active; after 3 failures it tries again in 2 minutes.
- **Potions:** one reminder for all potions that aren't in the hotbar, repeated only when the list changes or every 10 minutes; can be turned off.
- **Fixed:** yellow lights behind the hotbar (a garland) stretched the selected slot, the slot layout shifted and neither potions nor the fishing rod were found.
- **Fixed:** an error when the bobber wasn't visible at all from the start of watching.

**Catch**
- **History between launches:** the catch report shows this session, today, 7 days or all time (`catch_history.json` next to the settings); CSV for the chosen period.

**Program**
- **One-click update:** when a new version is out, the button in Settings becomes "Update to X" — it downloads the installer (the size is checked), starts it and closes the program. The portable version opens the release page.
- **Releases are published from the author's account** (the automatic build on GitHub only builds and keeps the files; `tools/publish_release.py`).
- **Tidy project folder:** sources in `src`, scripts in `scripts`, the built program with its logs and pictures in `program`.
- **102 tests**, including real screenshots from lava, a hotbar with yellow lights and bait numbers.

Everything the program can do: [README](https://github.com/Lepy0haa/TerrariaAutoFish#readme).

Requirements: Windows 10/11; in Terraria use **Windowed** or **Borderless** mode. Use in single player or on your own server — macros are often prohibited on public servers. Rod, bobber, buff and potion images are from the Terraria Wiki and belong to Re-Logic; this project is not affiliated with Re-Logic.

### Русский

Автоматическая рыбалка для **Terraria** (1.4.4, 1.4.5 и новее, tModLoader). Программа следит за поплавком на экране и подсекает, как только он уходит под воду (или под лаву), затем забрасывает снова. Сама берёт удочку в руки, находит поплавок, пьёт зелья из хотбара, может подсекать только нужный улов (зелье сонара), считает пойманное, пережидает Кровавую луну и вторжения и останавливается, если что-то пошло не так. Работает со снимками экрана, кликами мыши и нажатиями клавиш; память и файлы игры не меняет (только читает названия предметов из встроенных в игру таблиц перевода).

### Скачать
- **TerrariaAutoFish-1.5.0-setup.exe** — установщик: ставит программу для текущего пользователя (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», обновляет установленную версию; удалить — в «Параметры → Приложения».
- **TerrariaAutoFish-1.5.0-portable.zip** — портативная версия: распакуйте папку `TerrariaAutoFish` куда угодно (хоть на флешку) и запустите `TerrariaAutoFish.exe`; настройки хранятся рядом с программой.

### Новое в 1.5.0
**События и смерть**
- **События в чате пережидаются.** Игра пишет события в чат зелёным или фиолетовым; программа читает такую строку и сверяет с текстами игры: Кровавая, Тыквенная и Морозная луны и предупреждения о боссах — вытаскивает поплавок и пережидает ночь (~9 мин), солнечное затмение — день (~15 мин), гоблины, пираты, Ледяной легион, марсиане, небесное вторжение и пробуждение босса — 10 мин. Потом рыбалка продолжается сама (или нажмите HOME). Вторжение побеждено («Армия гоблинов побеждена!») — продолжает сразу.
- **Персонаж погиб — рыбалка останавливается совсем.** Красного в сердечках не осталось (а хотбар при этом виден — полноэкранная карта за смерть не считается): без самопродолжения, в том числе пока пережидается событие.

**Окошко поверх игры показывает режим работы**: что ловим (всё или только отмеченное по сонару) и в каком биоме, задание рыбака, зелья (и каких нет в хотбаре), за чем слежу, когда остановиться, сколько наживки и последний улов.

**Рыбалка**
- **Сдвиг картинки.** Если персонажа сдвинуло (враг, падение), вся картинка уезжает, и старая точка заброса может оказаться над сушей. Программа сравнивает место со снимком после последнего удачного заброса и переносит точку заброса и отметку на столько же, а не считает заброс неудачным.
- **Надпись сонара над лавой.** Лава и волны всё время меняются, и раньше казалось, что надпись висит всегда, — её появление пропускалось, а потом несколько надписей накладывались друг на друга. Теперь цвета, которые уже есть рядом на фоне, не принимаются за буквы: на настоящих снимках из лавы надпись находится и читается («Обсидирыба»).
- **Zoom узнаётся сам** по размеру поплавка при первом автопоиске (100–200 %) и сохраняется в настройках.
- **Точное число наживки и на сколько её хватит.** Число на удочке читается по образцам цифр игрового шрифта; засчитывается только уверенное прочтение (иначе, как раньше, — сколько в числе цифр).
- **Взять удочку:** потерявшееся нажатие повторяется; пока окно игры не активно, клавиши не нажимаются; после 3 неудач — новая попытка через 2 минуты.
- **Зелья:** одно напоминание про все зелья, которых нет в хотбаре; повтор — только если список изменился или раз в 10 минут; можно выключить.
- **Исправлено:** жёлтые огоньки за хотбаром (гирлянда) растягивали выбранный слот, раскладка слотов съезжала, и не находились ни зелья, ни удочка.
- **Исправлено:** ошибка, когда поплавка с самого начала слежения не было видно.

**Улов**
- **История между запусками:** отчёт об улове — за эту рыбалку, сегодня, 7 дней или всё время (`catch_history.json` рядом с настройками); CSV за выбранный период.

**Программа**
- **Обновление в один клик:** когда вышла новая версия, кнопка в настройках становится «Обновить до X» — скачивает установщик (размер сверяется), запускает его и закрывает программу. Портативная версия открывает страницу релиза.
- **Релизы выкладываются от аккаунта автора** (автосборка на GitHub только собирает и хранит файлы; `tools/publish_release.py`).
- **Порядок в папке проекта:** исходники — в `src`, скрипты — в `scripts`, собранная программа со своими журналами и картинками — в `program`.
- **102 теста**, в том числе на настоящих снимках из лавы, хотбаре с жёлтыми огоньками и числах наживки.

Всё, что умеет программа: [README](https://github.com/Lepy0haa/TerrariaAutoFish/blob/main/README.ru.md).
