## Terraria AutoFish 1.6.3

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught, waits out Blood Moons and invasions and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables).

### Download
- **TerrariaAutoFish-1.6.3-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.6.3-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### Fixed in 1.6.3
- **"Select the fishing rod automatically" kept switching to a slot without a fishing rod.** In Auto mode the program held on to a slot it had remembered earlier and pressed its number key before every cast — even when a fishing rod from another slot was already in hand and the remembered slot now held an axe. Now:
  - if a fishing rod is already in hand, the program fishes with it and remembers its slot;
  - before pressing the remembered slot it checks that the item there shows a bait count; if not (an axe, a sword…), the slot is forgotten and the fishing rod is looked for in the hotbar.

### Русский

Автоматическая рыбалка для **Terraria** (1.4.4, 1.4.5 и новее, tModLoader). Программа следит за поплавком на экране и подсекает, как только он уходит под воду (или под лаву), затем забрасывает снова. Сама берёт удочку в руки, находит поплавок, пьёт зелья из хотбара, может подсекать только нужный улов (зелье сонара), считает пойманное, пережидает Кровавую луну и вторжения и останавливается, если что-то пошло не так. Работает со снимками экрана, кликами мыши и нажатиями клавиш; память и файлы игры не меняет (только читает названия предметов из встроенных в игру таблиц перевода).

### Скачать
- **TerrariaAutoFish-1.6.3-setup.exe** — установщик: ставит программу для текущего пользователя (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», обновляет установленную версию; удалить — в «Параметры → Приложения».
- **TerrariaAutoFish-1.6.3-portable.zip** — портативная версия: распакуйте папку `TerrariaAutoFish` куда угодно (хоть на флешку) и запустите `TerrariaAutoFish.exe`; настройки хранятся рядом с программой.

### Исправлено в 1.6.3
- **«Сам брать удочку в руки» переключал на слот без удочки.** В режиме «Авто» программа держалась за слот, запомненный раньше, и жала его цифру перед каждым забросом — даже если в руках уже была удочка из другого слота, а в запомненном теперь лежал топор. Теперь:
  - если в руках уже удочка — программа ловит ею и запоминает её слот;
  - прежде чем нажать запомненный слот, программа проверяет, что на предмете в нём есть число наживки; если нет (топор, меч…) — слот забывается, и удочка ищется в хотбаре.
