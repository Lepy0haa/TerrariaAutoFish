## Terraria AutoFish 1.4.0

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables, see below).

### Download
- **TerrariaAutoFish-1.4.0-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.4.0-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### New in 1.4.0
**Lava fishing and catch names**
- **Catch names exactly as the game writes them.** Russian names on the Wiki often differ from the game's own translation ("Обсидиановая рыба" is "Обсидирыба" in the game, "Карп-огнепёрка" is "Золотоперый карп") — 74 of the 128 catch names didn't match, so the Sonar Potion text and the pickup text were often not recognized, especially in lava. Now the program reads the item names from the installed `Terraria.exe` (its built-in translation files) in a fraction of a second; the Wiki name is kept as a spare. Nothing from the game is copied or shipped with the program.
- **The bobber is found in lava.** Lava is opaque, so only the top of the bobber sticks out. The bobber images are now compared by the upper part as well: on a real lava screenshot the Glowing Fishing Bobber is found with a 0.96 match (it was taken for a Lava Moss bobber with 0.73 and you had to point at it).
- **Hint about heat distortion:** above lava the game makes the picture shimmer and letters double. If the Sonar text can't be read there, the log tells you to turn off *Settings → Video → Heat Distortion*.

**Catch**
- **Sonar text counts as a bite.** With "Choose the catch" on, the moment the Sonar Potion text appears above the bobber is a bite too — even if the bobber hasn't gone under yet.
- **Angler quest:** choose today's quest fish on the Catch tab. It is always hooked (even if it's unchecked in the lists); as soon as it's caught, fishing pauses and you get a notification.
- **Catch report** (Catch tab): what was caught this session, how many and where it lives; hooks, recognized / unrecognized, let go by sonar, hooks per hour; **Save CSV**.
- **Inventory full:** if the pickup text stops appearing for 3 hooks in a row (the catch falls on the ground), fishing pauses and you get a notification (Unattended tab).
- **Name memory:** once a name has been read confidently, the program remembers how it looks and recognizes it next time even when the Windows text recognition makes mistakes.

**Program**
- **Update check** once a day (and with the "Updates" button in Settings): only reads the public information about the latest release on GitHub; if there is a newer version — a notification and a link.
- **Tray icon:** a minimized window goes to the tray; the menu has Show window, Pause / resume, How to start and Quit.
- **First-run guide:** a few short pages on how to set up the game and start fishing. Opens on the first start, later with **F1** or from the tray menu.
- **Fewer antivirus false alarms:** the program is now a folder (`TerrariaAutoFish.exe` + `_internal`) instead of one self-extracting exe, is built without UPX packing and carries version information (name, version, author). It also starts faster.
- **Automatic builds on GitHub:** every change runs all tests; a version tag builds the installer and the portable version on GitHub's servers and publishes the release.
- The fishing engine is split into modules (`vision.py`, `fisher_gear.py`, `fisher_search.py`, `fisher_extras.py`, `fisher_catch.py`); **79 tests**, including a check that every message is translated to English.

### Features
**Fishing**
- **One-key start:** point at the water and press **HOME** — the program selects the rod, casts and finds the bobber. If it can't find it, point at the bobber and press **HOME** once more.
- **Finds the bobber by itself** by the Terraria Wiki images of every rod's bobber and every Fishing Bobber accessory (regular, Glowing, all Moss bobbers) — in water and in lava; adapts to sunset, night, caves and weather. If the bobber lands off to the side, searches wider and remembers the new spot.
- **Bite detection** by how much of the bobber is visible; a sharp dip counts too. Waves, rain, fish shadows, pets, sparkles and lightning flashes are ignored. **Auto-calibration** of the threshold, adjusted during every cast.
- **Pause / resume** with **HOME** keeping the points (also after restarting the program); **new points** with **END**.

**Automation**
- **Fishing rod:** finds the rod in the hotbar by the Wiki images (all 11 rods; weapons and tools are told apart by the bait count written on a rod), remembers its slot and takes it in hand before casting.
- **Potions from the hotbar:** Fishing, Crate, Sonar and Calming; when a buff ends, the program takes exactly that potion by its slot's number key, drinks it and takes the rod again. Or with Quick Buff (B).
- **Doesn't give up:** after failed casts retries every 2 s from the original mark, round after round; resumes by itself when you come back to the game window.

**Catch** (Sonar Potion)
- Lists for every biome (Forest, Ocean, Jungle, Snow, Desert, Corruption, Crimson, Hallow, Hallowed Desert, Glowing Mushroom, Dungeon, Space, Lava, Honey) plus Crates, Rare and Junk — 128 catches. The program reads what is biting with the Windows 10/11 text recognition (Russian and English) and hooks only what is checked; if the name can't be read confidently, it hooks.
- **"Fishing in: Auto"** recognizes the biome by what bites and what is picked up; after every hook "Caught: …" is written to the log.
- Angler quest fish, catch report with CSV.

**Unattended**
- **Health guard:** fewer health hearts two checks in a row — reels in, pauses, notifies.
- **Bait watch:** less than 10 — notification; no bait — stops.
- **Inventory full** — pauses.
- **When to finish:** after N minutes or N hooks; optionally shut the computer down 60 s later (can be cancelled).

**Interface**
- State and what to do; live picture of the bobber; "bobber visible" bar with the threshold; statistics; colored log (also saved to the `logs` folder for 14 days); **Collect a report** button.
- Small window over the game, Windows notifications, sounds, tray icon, first-run guide (F1).
- English and Russian; keys, Zoom, sensitivity, debug pictures and record mode in Settings.

Requirements: Windows 10/11; in Terraria use **Windowed** or **Borderless** mode. Use in single player or on your own server — macros are often prohibited on public servers. Rod, bobber, buff and potion images are from the Terraria Wiki and belong to Re-Logic; this project is not affiliated with Re-Logic.

### Русский

Автоматическая рыбалка для **Terraria** (1.4.4, 1.4.5 и новее, tModLoader). Программа следит за поплавком на экране и подсекает, как только он уходит под воду (или под лаву), затем забрасывает снова. Сама берёт удочку в руки, находит поплавок, пьёт зелья из хотбара, может подсекать только нужный улов (зелье сонара), считает пойманное и останавливается, если что-то пошло не так. Работает со снимками экрана, кликами мыши и нажатиями клавиш; память и файлы игры не меняет (только читает названия предметов из встроенных в игру таблиц перевода, см. ниже).

### Скачать
- **TerrariaAutoFish-1.4.0-setup.exe** — установщик: ставит программу для текущего пользователя (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», обновляет установленную версию; удалить — в «Параметры → Приложения».
- **TerrariaAutoFish-1.4.0-portable.zip** — портативная версия: распакуйте папку `TerrariaAutoFish` куда угодно (хоть на флешку) и запустите `TerrariaAutoFish.exe`; настройки хранятся рядом с программой.

### Новое в 1.4.0
**Рыбалка в лаве и названия улова**
- **Названия улова — точно как пишет игра.** Русские названия на Вики часто не совпадают с переводом в самой игре («Обсидиановая рыба» — в игре «Обсидирыба», «Карп-огнепёрка» — «Золотоперый карп»): не совпадали 74 названия из 128, поэтому надписи сонара и подбора часто не узнавались, особенно в лаве. Теперь программа за доли секунды читает названия предметов из установленной `Terraria.exe` (из встроенных в неё файлов перевода); название с Вики остаётся запасным. Ничего из игры не копируется и не распространяется с программой.
- **Поплавок находится в лаве.** Лава непрозрачная — из неё торчит только верхушка поплавка. Теперь картинки поплавков сравниваются и по верхней части: на настоящем снимке из лавы светящийся поплавок находится с совпадением 0.96 (раньше его принимало за поплавок из лавового мха с 0.73 и просило показать вручную).
- **Подсказка про искажение от тепла:** над лавой игра «дрожит» картинку, и буквы двоятся. Если надпись сонара там не читается, в журнале появится совет выключить *Настройки → Видео → «Искажение от тепла»*.

**Улов**
- **Надпись сонара — тоже поклёвка.** С включённым выбором улова момент, когда над поплавком появляется надпись зелья сонара, считается поклёвкой — даже если поплавок ещё не нырнул.
- **Задание рыбака:** выберите сегодняшнюю рыбу на вкладке «Улов». Она подсекается всегда (даже если не отмечена в списках); как только поймана — пауза и уведомление.
- **Отчёт об улове** (вкладка «Улов»): что поймано за сессию, сколько и где водится; подсечки, узнано / не узнано, отпущено сонаром, подсечек в час; **сохранить в CSV**.
- **Инвентарь полон:** если надпись о подборе пропала 3 подсечки подряд (улов падает на землю) — пауза и уведомление (вкладка «Без присмотра»).
- **Память надписей:** уверенно прочитанное название программа запоминает «в лицо» и в следующий раз узнаёт его, даже когда распознавание Windows ошибается.

**Программа**
- **Проверка обновлений** раз в сутки (и кнопкой «Обновления» в настройках): читает только публичные сведения о последнем релизе на GitHub; есть новее — уведомление и ссылка.
- **Значок в трее:** свёрнутое окно уходит в трей; в меню — «Показать окно», «Пауза / продолжить», «Как начать», «Выход».
- **Мастер первого запуска:** несколько коротких страниц — как настроить игру и начать рыбачить. Открывается при первом запуске, потом — по **F1** или из меню в трее.
- **Меньше ложных тревог антивирусов:** программа теперь — папка (`TerrariaAutoFish.exe` + `_internal`), а не один самораспаковывающийся exe, собрана без сжатия UPX и содержит сведения о версии (название, версия, автор). Заодно быстрее запускается.
- **Автоматическая сборка на GitHub:** на каждое изменение запускаются все тесты; по метке версии установщик и портативная версия собираются на серверах GitHub и выкладываются в релиз.
- Движок рыбалки разделён на модули (`vision.py`, `fisher_gear.py`, `fisher_search.py`, `fisher_extras.py`, `fisher_catch.py`); **79 тестов**, в том числе проверка, что все сообщения переведены на английский.

### Возможности
**Рыбалка**
- **Старт одной клавишей:** курсор на воду и **HOME** — программа возьмёт удочку, забросит и найдёт поплавок. Если не нашла — наведите на поплавок и нажмите **HOME** ещё раз.
- **Сама находит поплавок** по картинкам с Terraria Wiki — поплавкам всех удочек и всем аксессуарам-поплавкам (обычный, светящийся, все из мха) — в воде и в лаве; подстраивается под закат, ночь, пещеры и погоду. Если поплавок упал в стороне — ищет шире и запоминает новое место.
- **Поклёвка** — по тому, сколько поплавка видно; резкий нырок тоже считается. Волны, дождь, тени рыб, питомцы, искры и вспышки молний не мешают. **Автокалибровка** порога, подстраивается на каждом забросе.
- **Пауза / продолжение** — **HOME**, с теми же точками (и после перезапуска программы); **новые точки** — **END**.

**Автоматика**
- **Удочка:** находит удочку в хотбаре по картинкам с Вики (все 11 удочек; от оружия и инструментов отличает по числу наживки на удочке), запоминает слот и берёт её в руки перед забросом.
- **Зелья из хотбара:** рыбалки, ящиков, сонара и спокойствия; кончился бафф — программа берёт именно это зелье цифрой слота, выпивает и снова берёт удочку. Или быстрым баффом (B).
- **Не сдаётся:** после неудачных забросов пробует снова каждые 2 с от исходной отметки, круг за кругом; сама продолжает, когда вы возвращаетесь в окно игры.

**Улов** (зелье сонара)
- Списки для каждого биома (лес, океан, джунгли, снега, пустыня, порча, багрянец, святые земли, святая пустыня, светящиеся грибы, темница, космос, лава, мёд) и ящики, редкое, мусор — 128 видов улова. Программа читает, что клюёт, распознаванием текста Windows 10/11 (русский и английский) и подсекает только отмеченное; не прочитала уверенно — подсекает.
- **«Где рыбачу: Авто»** — биом узнаётся по тому, что клюёт и что подобрано; после каждой подсечки в журнал пишется «Поймал: …».
- Рыба для задания рыбака, отчёт об улове с CSV.

**Без присмотра**
- **Защита персонажа:** сердечек меньше две проверки подряд — вытаскивает поплавок, пауза, уведомление.
- **Наживка:** меньше 10 — уведомление; кончилась — остановка.
- **Инвентарь полон** — пауза.
- **Когда закончить:** через N минут или N подсечек; по желанию — выключить компьютер через 60 с (можно отменить).

**Интерфейс**
- Что происходит и что делать; живая картинка поплавка; шкала «видно поплавка» с порогом; статистика; цветной журнал (ещё и в папке `logs`, 14 дней); кнопка **«Собрать отчёт»**.
- Окошко поверх игры, уведомления Windows, звуки, значок в трее, мастер первого запуска (F1).
- Русский и английский; клавиши, Zoom, чувствительность, отладочные картинки и режим записи — в настройках.

Требования: Windows 10/11; в Terraria — режим **«Оконный»** или **«Без рамки»**. Используйте в одиночной игре или на своём сервере — на публичных серверах макросы часто запрещены. Картинки удочек, поплавков, баффов и зелий взяты с Terraria Wiki и принадлежат Re-Logic; проект не связан с Re-Logic.
