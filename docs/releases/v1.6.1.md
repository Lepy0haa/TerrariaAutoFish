## Terraria AutoFish 1.6.1

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught, waits out Blood Moons and invasions and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables).

### Download
- **TerrariaAutoFish-1.6.1-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.6.1-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### New in 1.6.0
- **Diagnostics** (Settings tab): one check of everything needed for fishing — the game window, the hotbar and interface scale, the fishing rod and bait, potions in the hotbar and active buffs, health hearts, Windows text recognition languages, item names from the game, Zoom and saved points — each with what to do. The result is shown in a window and saved to `data\diagnostics_….txt`.
- **⚑ Something's wrong** (Fishing tab): the last 60 search, bite and text pictures (kept in memory even with debug pictures off), a screenshot of the game window, the end of the log and the settings go into one `data\reports\mistake_….zip` — send it, and a strange case can be analysed right away.
- **Events and death on real frames:** a new event line from the chat and the hearts at the moment of death are kept as pictures, and what was read is written to the log once — so the event recognition can be checked and improved on your games.

- **Less CPU:** while waiting for a bite the program takes an even 60 pictures a second (as many as the game draws) instead of up to ~150–200, and doesn't ask Windows for the game's process name on every picture — on the test game 23% → 9% of one core. The stats show the program's CPU load.
- **One-click update for the portable version too:** it downloads the new zip, closes, replaces its files (settings and data are kept) and starts again.
- **Second monitor:** the program window and the small window open where they were left, also on a monitor with negative coordinates; fishing on such a monitor is covered by a test.
- **"Support the author"** window (appears once donation links are added).
- **114 tests.**

### Fixed in 1.5.1
- **The program lost the bobber and followed an empty place.** In a dark cave the wide search took an empty spot on the water edge right next to the real bobber: the check "is it our bobber" looked for the Wiki image with too low a threshold (0.65, the empty edge gave 0.69). The remembered bobber image then "learned" the water edge, which looks the same along the whole surface, and the program watched an empty place — no bites for 45 s again and again, and its clicks got out of step with the real casts (a "hook" only cast the bobber). Now:
  - a found place must look like the Wiki image of this bobber type (0.75+, the real bobber gives 0.95);
  - the wide search takes the place most similar to the bobber in the zone;
  - a place found only by the remembered image must pass the same check;
  - after 3 recasts in a row without a bite the original bobber image and mark are restored.
- **The program is in the project folder again** (`TerrariaAutoFish.exe` + `_internal`); everything it writes itself — logs, debug pictures, records, hotbar snapshots, reports — is in one `data` folder next to it.

### New in 1.5.0
**Events and death**
- **Events in chat are waited out.** The game writes events in chat in green or purple; the program reads such a line and compares it with the game's texts: Blood, Pumpkin and Frost Moon and boss warnings — it reels in and waits one night (~9 min), solar eclipse — a day (~15 min), goblins, pirates, Frost Legion, martians, celestial invasion and a boss awakening — 10 min. Then fishing continues by itself (or press HOME). When an invasion is defeated ("A goblin army has been defeated!"), fishing continues at once.
- **The character died — fishing stops completely.** No red left in the health hearts (while the hotbar is visible, so the fullscreen map isn't taken for death): no automatic resume, also while an event is being waited out.

**The small window over the game shows the mode**: what is caught (everything or only checked with the Sonar Potion) and in which biome, the Angler quest, potions (and which aren't in the hotbar), what is watched, when to stop, how much bait is left and the last catch.

**Fishing**
- **A moved picture is followed.** If the character is pushed (an enemy, a fall), the whole picture moves and the old cast point may be over land. The program compares the place with its picture from the last successful cast and moves the cast point and the mark by the same amount instead of failing.
- **Sonar text over lava.** Lava and waves change all the time, and before the text seemed to be always there — its appearance was missed, and later several texts overlapped. Now colors already present nearby in the background are not taken for letters: on real lava screenshots the text is found and read ("Обсидирыба").
- **Zoom is recognized by itself** by the bobber's size on the first automatic search (100–200%) and saved in the settings.
- **Exact bait count and how long it lasts.** The number on the fishing rod is read by samples of the game's digits; only a confident read is used (otherwise the number of digits, as before).
- **Taking the rod:** a lost key press is repeated; keys are never pressed while the game window isn't active; after 3 failures it tries again in 2 minutes.
- **Potions:** one reminder for all potions that aren't in the hotbar, repeated only when the list changes or every 10 minutes; can be turned off.
- **Fixed:** yellow lights behind the hotbar (a garland) stretched the selected slot, the slot layout shifted and neither potions nor the fishing rod were found.
- **Fixed:** an error when the bobber wasn't visible at all from the start of watching.

**Catch**
- **History between launches:** the catch report shows this session, today, 7 days or all time (`catch_history.json` next to the settings); CSV for the chosen period.

**Program**
- **One-click update:** when a new version is out, the button in Settings becomes "Update to X" — it downloads the installer (the size is checked), starts it and closes the program. The portable version opens the release page.
- **Releases are published from the author's account** (the automatic build on GitHub only builds and keeps the files; `tools/publish_release.py`).
- **Tidy project folder:** sources in `src`, scripts in `scripts`, the built program with its logs and pictures in `program`.
- **114 tests**, including real screenshots from lava, a hotbar with yellow lights and bait numbers.

### Features
**Fishing**
- **One-key start:** point at the water and press **HOME** — the program selects the rod, casts and finds the bobber. If it can't find it, point at the bobber and press **HOME** once more.
- **Finds the bobber by itself** by the Terraria Wiki images of every rod's bobber and every Fishing Bobber accessory — in water and in lava; adapts to sunset, night, caves and weather; follows a moved picture.
- **Bite detection** by how much of the bobber is visible; a sharp dip and the Sonar text count too. Waves, rain, fish shadows, pets, sparkles and lightning flashes are ignored. **Auto-calibration** of the threshold.
- **Pause / resume** with **HOME** keeping the points (also after restarting the program); **new points** with **END**.

**Automation**
- **Fishing rod:** finds the rod in the hotbar (all 11 rods), remembers its slot and takes it in hand before casting.
- **Potions from the hotbar:** Fishing, Crate, Sonar and Calming — exactly the needed potion; or with Quick Buff (B).
- **Doesn't give up:** retries every 2 s, round after round; resumes by itself when you come back to the game.

**Catch** (Sonar Potion)
- Lists for every biome plus Crates, Rare and Junk — 128 catches; names exactly as the game writes them. The program hooks only what is checked; if the name can't be read confidently, it hooks.
- **"Fishing in: Auto"** recognizes the biome by what bites and what is picked up; Angler quest fish; catch report and history with CSV.

**Unattended**
- **Health guard** (damage — reel in and pause), **death** — stop completely, **events** in chat — wait out and continue.
- **Bait:** exact count and time left; less than 10 — notification; no bait — stop. **Inventory full** — pause.
- **When to finish:** after N minutes or N hooks; optionally shut the computer down.

**Interface**
- State, live picture of the bobber, "bobber visible" bar, statistics, colored log (also in `logs`, 14 days), **Collect a report**.
- Small window over the game with the mode, Windows notifications, sounds, tray icon, first-run guide (F1), update in one click.
- English and Russian.

Requirements: Windows 10/11; in Terraria use **Windowed** or **Borderless** mode. Use in single player or on your own server — macros are often prohibited on public servers. Rod, bobber, buff and potion images are from the Terraria Wiki and belong to Re-Logic; this project is not affiliated with Re-Logic.

### Исправлено в 1.5.1
- **Программа теряла поплавок и следила за пустым местом.** В тёмной пещере широкий поиск взял пустое место на кромке воды рядом с настоящим поплавком: проверка «наш ли это поплавок» искала картинку с Вики со слишком низким порогом (0.65, а пустая кромка давала 0.69). Запомненный образец поплавка «переучивался» на кромку воды, одинаковую по всей поверхности, и программа следила за пустым местом — «нет поклёвки 45 с» раз за разом, а её клики сбивались с настоящими забросами («подсечка» только забрасывала поплавок). Теперь:
  - найденное место должно быть похоже на картинку этого вида поплавка с Вики (от 0.75, настоящий поплавок даёт 0.95);
  - широкий поиск берёт в зоне место, больше всего похожее на поплавок;
  - место, найденное только по образцу, проходит ту же проверку;
  - после 3 перезабросов подряд без поклёвки возвращаются исходные образец и отметка поплавка.
- **Программа снова в папке проекта** (`TerrariaAutoFish.exe` + `_internal`); всё, что она пишет сама, — журналы, отладочные картинки, записи, снимки хотбара, отчёты — в одной папке `data` рядом с ней.

### Новое в 1.5.0
**События и смерть**
- **События в чате пережидаются.** Игра пишет события в чат зелёным или фиолетовым; программа читает такую строку и сверяет с текстами игры: Кровавая, Тыквенная и Морозная луны и предупреждения о боссах — вытаскивает поплавок и пережидает ночь (~9 мин), солнечное затмение — день (~15 мин), гоблины, пираты, Ледяной легион, марсиане, небесное вторжение и пробуждение босса — 10 мин. Потом рыбалка продолжается сама (или нажмите HOME). Вторжение побеждено («Армия гоблинов побеждена!») — продолжает сразу.
- **Персонаж погиб — рыбалка останавливается совсем.** Красного в сердечках не осталось (а хотбар при этом виден — полноэкранная карта за смерть не считается): без самопродолжения, в том числе пока пережидается событие.

**Окошко поверх игры показывает режим работы**: что ловим (всё или только отмеченное по сонару) и в каком биоме, задание рыбака, зелья (и каких нет в хотбаре), за чем слежу, когда остановиться, сколько наживки и последний улов.

**Рыбалка**
- **Сдвиг картинки.** Если персонажа сдвинуло (враг, падение), вся картинка уезжает, и старая точка заброса может оказаться над сушей. Программа сравнивает место со снимком после последнего удачного заброса и переносит точку заброса и отметку на столько же, а не считает заброс неудачным.
- **Надпись сонара над лавой.** Лава и волны всё время меняются, и раньше казалось, что надпись висит всегда, — её появление пропускалось, а потом несколько надписей накладывались друг на друга. Теперь цвета, которые уже есть рядом на фоне, не принимаются за буквы: на настоящих снимках из лавы надпись находится и читается («Обсидирыба»).
- **Zoom узнаётся сам** по размеру поплавка при первом автопоиске (100–200 %) и сохраняется в настройках.
- **Точное число наживки и на сколько её хватит.** Число на удочке читается по образцам цифр игрового шрифта; засчитывается только уверенное прочтение (иначе, как раньше, — сколько в числе цифр).
- **Взять удочку:** потерявшееся нажатие повторяется; пока окно игры не активно, клавиши не нажимаются; после 3 неудач — новая попытка через 2 минуты.
- **Зелья:** одно напоминание про все зелья, которых нет в хотбаре; повтор — только если список изменился или раз в 10 минут; можно выключить.
- **Исправлено:** жёлтые огоньки за хотбаром (гирлянда) растягивали выбранный слот, раскладка слотов съезжала, и не находились ни зелья, ни удочка.
- **Исправлено:** ошибка, когда поплавка с самого начала слежения не было видно.

**Улов**
- **История между запусками:** отчёт об улове — за эту рыбалку, сегодня, 7 дней или всё время (`catch_history.json` рядом с настройками); CSV за выбранный период.

**Программа**
- **Обновление в один клик:** когда вышла новая версия, кнопка в настройках становится «Обновить до X» — скачивает установщик (размер сверяется), запускает его и закрывает программу. Портативная версия открывает страницу релиза.

- **Порядок в папке проекта:** исходники — в `src`, скрипты — в `scripts`, собранная программа со своими журналами и картинками — в `program`.
- **114 тестов**, в том числе на настоящих снимках из лавы, хотбаре с жёлтыми огоньками и числах наживки.

### Возможности
**Рыбалка**
- **Старт одной клавишей:** курсор на воду и **HOME** — программа возьмёт удочку, забросит и найдёт поплавок. Если не нашла — наведите на поплавок и нажмите **HOME** ещё раз.
- **Сама находит поплавок** по картинкам с Terraria Wiki — поплавкам всех удочек и всем аксессуарам-поплавкам — в воде и в лаве; подстраивается под закат, ночь, пещеры и погоду; следует за сдвигом картинки.
- **Поклёвка** — по тому, сколько поплавка видно; резкий нырок и надпись сонара тоже считаются. Волны, дождь, тени рыб, питомцы, искры и вспышки молний не мешают. **Автокалибровка** порога.
- **Пауза / продолжение** — **HOME**, с теми же точками (и после перезапуска программы); **новые точки** — **END**.

**Автоматика**
- **Удочка:** находит удочку в хотбаре (все 11 удочек), запоминает слот и берёт её в руки перед забросом.
- **Зелья из хотбара:** рыбалки, ящиков, сонара и спокойствия — именно нужное; или быстрым баффом (B).
- **Не сдаётся:** пробует снова каждые 2 с, круг за кругом; сама продолжает, когда вы возвращаетесь в игру.

**Улов** (зелье сонара)
- Списки для каждого биома, а ещё ящики, редкое и мусор — 128 видов улова; названия — ровно как пишет игра. Подсекается только отмеченное; не прочитала название уверенно — подсекает.
- **«Где рыбачу: Авто»** — биом узнаётся по тому, что клюёт и что подобрано; рыба для задания рыбака; отчёт и история улова с CSV.

**Без присмотра**
- **Защита персонажа** (урон — вытащить поплавок и пауза), **смерть** — остановка совсем, **события** в чате — переждать и продолжить.
- **Наживка:** точное число и на сколько хватит; меньше 10 — уведомление; кончилась — остановка. **Инвентарь полон** — пауза.
- **Когда закончить:** через N минут или N подсечек; по желанию — выключить компьютер.

**Интерфейс**
- Что происходит, живая картинка поплавка, шкала «видно поплавка», статистика, цветной журнал (ещё и в `logs`, 14 дней), **«Собрать отчёт»**.
- Окошко поверх игры с режимом работы, уведомления Windows, звуки, значок в трее, мастер первого запуска (F1), обновление в один клик.
- Русский и английский.

Требования: Windows 10/11; в Terraria — режим **«Оконный»** или **«Без рамки»**. Используйте в одиночной игре или на своём сервере — на публичных серверах макросы часто запрещены. Картинки удочек, поплавков, баффов и зелий взяты с Terraria Wiki и принадлежат Re-Logic; проект не связан с Re-Logic.
