## Terraria AutoFish 1.6.2

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught, waits out Blood Moons and invasions and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables).

### Download
- **TerrariaAutoFish-1.6.2-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.6.2-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### Fixed in 1.6.2
- **The bobbers of the Golden and Mechanic's fishing rods weren't found.** At night a dim bobber sitting deep in the liquid didn't make it into the few "most noticeable" spots that were checked, and a random spot next to the character (a creature, the edge of the ground) was taken for a bobber. Now:
  - 16 spots are checked instead of 8–10 (all Zooms — only for the best three, so the first search stays fast);
  - a spot next to the character or behind them is trusted less: the bobber flies from the character towards the cursor;
  - the first search looks further beyond the cursor — fast rods throw the bobber further than the cursor.
  If the bobber isn't visible at all (for example, it sank), the program asks you to point at it instead of taking something else.

### Русский

Автоматическая рыбалка для **Terraria** (1.4.4, 1.4.5 и новее, tModLoader). Программа следит за поплавком на экране и подсекает, как только он уходит под воду (или под лаву), затем забрасывает снова. Сама берёт удочку в руки, находит поплавок, пьёт зелья из хотбара, может подсекать только нужный улов (зелье сонара), считает пойманное, пережидает Кровавую луну и вторжения и останавливается, если что-то пошло не так. Работает со снимками экрана, кликами мыши и нажатиями клавиш; память и файлы игры не меняет (только читает названия предметов из встроенных в игру таблиц перевода).

### Скачать
- **TerrariaAutoFish-1.6.2-setup.exe** — установщик: ставит программу для текущего пользователя (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», обновляет установленную версию; удалить — в «Параметры → Приложения».
- **TerrariaAutoFish-1.6.2-portable.zip** — портативная версия: распакуйте папку `TerrariaAutoFish` куда угодно (хоть на флешку) и запустите `TerrariaAutoFish.exe`; настройки хранятся рядом с программой.

### Исправлено в 1.6.2
- **Не находился поплавок золотой и механической удочек.** Ночью тусклый поплавок, сидящий глубоко в жидкости, не попадал в несколько «самых заметных» мест, которые проверялись, а за поплавок принималось случайное место рядом с персонажем (существо, край земли). Теперь:
  - проверяются 16 мест вместо 8–10 (все Zoom — только у трёх лучших, чтобы первый поиск оставался быстрым);
  - месту рядом с персонажем или позади него доверия меньше: поплавок летит от персонажа в сторону курсора;
  - первый поиск смотрит дальше за курсор — быстрые удочки забрасывают дальше курсора.
  Если поплавка совсем не видно (например, утонул), программа просит показать его, а не берёт что-то другое.
