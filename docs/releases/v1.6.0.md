## Terraria AutoFish 1.6.0

**English** · [Русский ниже](#русский)

Automatic fishing for **Terraria** (1.4.4, 1.4.5 and newer, tModLoader). The program watches the bobber on the screen and hooks the fish the moment the bobber goes under water (or lava), then casts again. It takes the fishing rod in hand, finds the bobber by itself, drinks potions from the hotbar, can hook only the catch you want (Sonar Potion), counts what is caught, waits out Blood Moons and invasions and stops when something goes wrong. It works with screenshots, mouse clicks and key presses; it never changes the game's memory or files (it only reads item names from the game's own translation tables).

### Download
- **TerrariaAutoFish-1.6.0-setup.exe** — installer: installs for the current user (no admin rights), adds Desktop and Start menu shortcuts, updates an existing installation; remove it in Settings → Apps.
- **TerrariaAutoFish-1.6.0-portable.zip** — portable version: unpack the `TerrariaAutoFish` folder anywhere (even a USB stick) and run `TerrariaAutoFish.exe`; settings are kept next to the program.

### New in 1.6.0
- **Diagnostics** (Settings tab): one check of everything needed for fishing — the game window, the hotbar and interface scale, the fishing rod and bait, potions in the hotbar and active buffs, health hearts, Windows text recognition languages, item names from the game, Zoom and saved points — each with what to do. The result is shown in a window and saved to `data\diagnostics_….txt`.
- **⚑ Something's wrong** (Fishing tab): the last 60 search, bite and text pictures (kept in memory even with debug pictures off), a screenshot of the game window, the end of the log and the settings go into one `data\reports\mistake_….zip` — send it, and a strange case can be analysed right away.
- **Events and death on real frames:** a new event line from the chat and the hearts at the moment of death are kept as pictures, and what was read is written to the log once — so the event recognition can be checked and improved on your games.
- **Small window options:** opacity, text size, the mode block on/off, hide while fishing is paused.
- **Charts in the catch report:** the catch over 14 days and by hour of day, how many crates and rare items, which biome gave the most.
- **Less CPU:** while waiting for a bite the program takes an even 60 pictures a second (as many as the game draws) instead of up to ~150–200, and doesn't ask Windows for the game's process name on every picture — on the test game 23% → 9% of one core. The stats show the program's CPU load.
- **One-click update for the portable version too:** it downloads the new zip, closes, replaces its files (settings and data are kept) and starts again.
- **Second monitor:** the program window and the small window open where they were left, also on a monitor with negative coordinates; fishing on such a monitor is covered by a test.
- **114 tests.**

Everything the program can do: [README](https://github.com/Lepy0haa/TerrariaAutoFish#readme).

Requirements: Windows 10/11; in Terraria use **Windowed** or **Borderless** mode. Use in single player or on your own server — macros are often prohibited on public servers. Rod, bobber, buff and potion images are from the Terraria Wiki and belong to Re-Logic; this project is not affiliated with Re-Logic.

### Русский

Автоматическая рыбалка для **Terraria** (1.4.4, 1.4.5 и новее, tModLoader). Программа следит за поплавком на экране и подсекает, как только он уходит под воду (или под лаву), затем забрасывает снова. Сама берёт удочку в руки, находит поплавок, пьёт зелья из хотбара, может подсекать только нужный улов (зелье сонара), считает пойманное, пережидает Кровавую луну и вторжения и останавливается, если что-то пошло не так. Работает со снимками экрана, кликами мыши и нажатиями клавиш; память и файлы игры не меняет (только читает названия предметов из встроенных в игру таблиц перевода).

### Скачать
- **TerrariaAutoFish-1.6.0-setup.exe** — установщик: ставит программу для текущего пользователя (без прав администратора), создаёт ярлыки на рабочем столе и в меню «Пуск», обновляет установленную версию; удалить — в «Параметры → Приложения».
- **TerrariaAutoFish-1.6.0-portable.zip** — портативная версия: распакуйте папку `TerrariaAutoFish` куда угодно (хоть на флешку) и запустите `TerrariaAutoFish.exe`; настройки хранятся рядом с программой.

### Новое в 1.6.0
- **«Диагностика»** (вкладка «Настройки»): одна проверка всего, что нужно для рыбалки, — окно игры, хотбар и масштаб интерфейса, удочка и наживка, зелья в хотбаре и баффы, сердечки здоровья, языки распознавания текста Windows, названия из игры, Zoom и сохранённые точки — на каждый пункт подсказка, что сделать. Итог — в окне и в `data\diagnostics_….txt`.
- **«⚑ Что-то не так»** (вкладка «Рыбалка»): последние 60 картинок поиска, поклёвок и надписей (хранятся в памяти даже без отладочных картинок), снимок окна игры, конец журнала и настройки — в один `data\reports\mistake_….zip`. Пришлите его — и странный случай можно разобрать сразу.
- **События и смерть на настоящих кадрах:** новая строка события из чата и сердечки в момент смерти сохраняются картинками, а прочитанное один раз пишется в журнал — так распознавание событий можно проверить и улучшить на ваших играх.
- **Настройки окошка поверх игры:** непрозрачность, размер текста, блок режима вкл/выкл, прятать на паузе.
- **Графики в отчёте об улове:** улов за 14 дней и по часам суток, сколько ящиков и редкого, какой биом дал больше всего.
- **Меньше нагрузка на процессор:** пока ждёт поклёвку, программа делает ровно 60 снимков в секунду (столько, сколько рисует игра) вместо примерно 150–200 и не спрашивает у Windows имя процесса игры на каждом снимке — на тестовой игре 23 % → 9 % одного ядра. В статистике видна нагрузка программы.
- **Обновление в один клик и для портативной версии:** скачивает новый архив, закрывается, заменяет свои файлы (настройки и данные сохраняются) и запускается снова.
- **Второй монитор:** окно программы и окошко открываются там, где их оставили, и на мониторе с отрицательными координатами; рыбалка на таком мониторе проверена тестом.
- **114 тестов.**
